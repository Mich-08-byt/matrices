
Matrix Operations in C++

Description

This project is a C++ program for performing basic mathematical operations on 2×2 and 3×3 matrices.

It was developed as a programming practice project to improve my understanding of C++ and matrix operations.

Features

- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Matrix trace
- Matrix determinant
- Matrix transpose (2×2 matrices)
- Matrix inverse

Technologies

- C++
- Standard Input/Output ("iostream")

Project Structure

- "main.cpp": Main program and user interaction
- "M2x2.cpp" and "M2x2.h": Implementation and declarations for 2×2 matrix operations
- "M3x3.cpp" and "M3x3.h": Implementation and declarations for 3×3 matrix operations

How to Compile

If you have a C++ compiler such as g++, compile the source files together:

g++ main.cpp M2x2.cpp M3x3.cpp -o matrices

Run the program:

./matrices

On Windows, run the generated executable with:

matrices.exe
